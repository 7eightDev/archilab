# Pagine Progetti, dettaglio progetto e Hero dai progetti — piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** aggiungere `/progetti` (elenco filtrabile), `/progetti/[slug]` (dettaglio), un Hero della home alimentato da 5 progetti scelti e un drawer dei contatti nelle pagine progetti.

**Architecture:** si estende l'architettura a strati esistente (`app/_domain` → `app/_application` → `app/_infrastructure` → `app/_components` e le pagine). I dati restano in memoria dietro `ProjectRepository`, così un database futuro cambierà solo l'adapter. Le pagine sono Server Components: `/progetti` legge `searchParams` dentro `<Suspense>` (richiesto da `cacheComponents: true`), il dettaglio si genera in anticipo con `generateStaticParams`.

**Tech Stack:** Next.js 16.4 (App Router, `cacheComponents`), React 19.3, TypeScript, Zod 4, Tailwind CSS 4, Base UI 1.9 (Dialog), lucide-react, Jest e Testing Library.

**Spec:** [docs/superpowers/specs/2026-10-23-progetti-design.md](../specs/2026-10-23-progetti-design.md). Leggila prima di ogni task: questo piano rimanda a lei per testi, misure e ordine delle sezioni. Riferimento visivo: `Archilab website wireframes/Archilab Progetti.dc.html` (locale, escluso dal repo), board 1a–1q.

## Global Constraints

- Prima di scrivere codice Next.js leggi la guida pertinente in `node_modules/next/dist/docs/` (regola di `AGENTS.md`). In particolare `01-app/02-guides/optimizing-the-static-shell.md` per `searchParams` dentro `<Suspense>`.
- Nessuna cartella `src/`: i livelli stanno in `app/_*`.
- Rispetta [DESIGN.md](../../../DESIGN.md): solo tema scuro; ottone `#bc9a62` unico accento; raggio 0 ovunque, tranne i pallini da 11px e la maniglia da 44px; nessun `box-shadow`; nessun carattere Unicode al posto delle icone (usa lucide-react); niente numerazione 01/02/03 su card, elenchi o immagini.
- Mai segnaposto visibili: se un dato manca, l'elemento si omette.
- Area di tocco minima 44px; pulsante primario alto 52px.
- I testi dell'interfaccia sono in italiano e in prima persona. Commenti nel codice e nomi dei test in inglese, come nel resto del repo.
- Ogni movimento rispetta `prefers-reduced-motion` (`motion-reduce:` di Tailwind).
- Comandi: test `pnpm test -- <path>`, lint `pnpm lint`, tipi `pnpm exec tsc --noEmit`, build `pnpm build`.
- Commit piccoli, uno per task, con il messaggio indicato. Nessuna riga `Co-Authored-By` né altri riferimenti ad Anthropic o Claude nei commit.

## Review Focus

1. **Filtro manipolato a mano**: `?categoria=Interni`, `?categoria=interni&categoria=pubblico` (array) o `?categoria=` (vuoto) devono mostrare tutti i progetti con "Tutti" attivo, senza errori. Test nel Task 13.
2. **Clic con modificatori su un trigger del drawer**: Ctrl/Cmd+clic o clic centrale su "Scrivimi" devono seguire il link `/#contatti` (nuova scheda) invece di aprire il drawer. Test nel Task 10.
3. **Progetto in evidenza fuori dal filtro**: con `?categoria=interni` la riga CASO STUDIO non compare e il progetto in evidenza non finisce nella griglia. Test nel Task 13.
4. **Didascalia dell'Hero senza dati**: un progetto senza `scope` né `areaSqm` produce una didascalia vuota; il link mostra solo "Guarda il progetto", senza trattino iniziale. Test nel Task 6.
5. **Unità al singolare**: `durationMonths: 1` mostra "1 mese", non "1 mesi". Test nel Task 4.
